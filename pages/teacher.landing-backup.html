Project Purpose

Problem Statement & Mission

Section 1.1 – 1.3 SRS

The ADHD Online Learning Challenge

Traditional e-learning platforms (e.g., Moodle, Google Classroom, Zoom) evaluate student engagement using naive metrics: login counts, clicks, and session durations. These parameters are fundamentally inadequate for representing genuine attention.

Neurodivergent students, particularly those with Attention Deficit Hyperactivity Disorder (ADHD), struggle significantly with sustained focus in virtual classrooms. In crowded online sessions, subtle distractions go unnoticed, leading to progressive academic disengagement.

The Neuro-Focus Solution

Neuro-Focus creates a smart, inclusive digital learning ecosystem by replacing manual guesswork with objective AI-driven behavioral analytics:

  • ✓ Continuous eye-gaze extraction and head-pose estimation via MediaPipe.
  • ✓ Temporal behavioral classification using an LSTM recurrent neural network.
  • ✓ Instantaneous attention score visualization on the Teacher Dashboard.
  • ✓ Automated adaptive re-engagement prompts whenever focus lapses are flagged.
Core Architecture

Real-Time AI Processing Pipeline

Figure 2 & 5 System Design

Step 01
Webcam Ingestion

Client browser captures live frames locally via HTML5 MediaStream API at zero cloud storage footprint.

Step 02
Landmark Extraction

MediaPipe Face Mesh isolates 478 3D landmarks to extract normalized eye gaze ratios and head orientation angles.

Step 03
LSTM Classification

Recurrent neural network models temporal sequence patterns across sliding frame windows to predict cognitive states.

Step 04
Live Dashboard & Alerts

Attention scores stream to the teacher interface, triggering real-time Chart.js updates and adaptive student nudges.
